# Calculator
Cute basic arithmetic calculator


# *Getting Started* 
1. Clone repo
2. Open solution in VS code using a windows form format
3. Build calculation in Form1[Designer] and run the code. You will need to make 19 buttons and a text box.



# *features*

Basic Arithmetic:

     - addition
    - subtraction
    - multiplication
     - division
      - modulo

- Clear Button
- Clear Entery
- Equals


# *Built With*

- Language: C#
- .NET
- Windows form
